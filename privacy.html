隐私政策声明

最后更新：2026年9月19日

欢迎访问 CrCLARE 工作室站点。我们致力于保护您的隐私，并尽可能保持数据处理透明。以下是我们的具体声明：

1. 开源与可审计性

除 Pass 服务外，本工作室所有站点均在 GitHub 仓库公开，代码随时可供社区审计。我们不隐藏任何数据处理逻辑，您可以自行审查源码以验证本声明的真实性。

2. 数据收集与使用

本工作室站点（Pass 除外）均为纯静态站点。我们不会主动记录或收集任何您的个人身份信息。

唯一的例外是：当您使用 Twikoo 评论系统时，您主动输入的邮箱、昵称、网站地址，以及发送评论时系统自动获取的 IP 地址，会被存储于 MongoDB 数据库中。这些数据仅用于展示您的评论及防止垃圾留言。

为了保障评论系统的安全与纯净，我们在评论流程中接入了以下第三方服务：

  • 极验（GeeTest）：用于人机验证（设备指纹），防止机器人自动发布垃圾评论。在您进行评论验证时，极验会收集您的设备信息、网络信息等，用于生成设备指纹，以区分真实用户与自动化脚本。
  • Akismet：用于反垃圾评论过滤。您提交的评论内容、评论者姓名、邮箱地址、IP 地址及评论者URL会被发送至 Akismet 服务进行检测，以判断是否为垃圾评论。Akismet 不会将这些数据用于其他目的，且数据保留期通常在两周至九十天之间。

特别声明：对于使用 Chronos Seal 项目的用户，您的加密主种子（Seed）仅在本地生成，绝不会上传至我们的任何服务器，我们无权也无法获取您的加密密钥。

3. 基础设施与托管服务

除 Pass 服务外，本工作室旗下的站点与后端服务，按业务类型分布依托于以下基础设施平台，均符合业界安全标准：

  • GitHub：所有站点的代码托管与版本控制。
  • GitHub Pages：承载工作室主页与文档站点的静态托管。
  • Vercel：承载博客、评论系统以及 Chronos Seal 盲代理服务。评论系统与代理服务均在 Serverless 无服务器函数中运行。
  • Cloudflare Pages：承载图床与网盘。
  • Cloudflare：统一负责所有站点的 DNS 解析、CDN 加速与 WAF 安全防护。

上述平台会在服务器层面自动处理访问流量日志（如 IP 地址、访问时间、请求路径等）。这些日志仅用于安全防护与访问统计，各平台的具体数据处理受其各自隐私政策约束。

4. Cookie 与第三方分析

我们部分站点使用 Google Analytics 进行匿名流量分析。该服务受 Google 隐私政策保护。若未来我们面向特定合规地区（如欧盟）启用严格的 Cookie 同意管理，我们将在此更新相关说明。

5. Pass 服务

如果您使用 CrCLARE 旗下的 Pass 服务，由于涉及账号认证，具体的数据处理与隐私保护条款，请以 Logto 隐私政策为准。

6. 数据共享与披露

我们承诺不会与任何第三方个人、公司或组织分享、出售或披露您的个人信息。为了提供上述服务，我们接入了以下第三方基础设施与工具，其数据处理受各自隐私政策约束：

  • MongoDB（评论系统数据库）：https://www.mongodb.com/legal/privacy/privacy-policy
  • Logto（Pass 服务认证）：https://logto.io/terms/privacy-policy
  • 极验（人机验证）：https://www2.geetest.com/Private/fingerprint
  • Akismet（反垃圾评论）：https://akismet.com/privacy/
  • Google Analytics（匿名流量分析）：https://policies.google.com/privacy
  • GitHub（代码托管，Pages 服务承载主页与文档）：https://docs.github.com/zh/site-policy/privacy-policies
  • Vercel（博客、评论与盲代理托管）：https://vercel.com/legal/privacy-notice
  • Cloudflare Pages（图床与网盘托管）：https://www.cloudflare.com/privacypolicy/
  • Cloudflare（CDN 与安全防护）：https://www.cloudflare-cn.com/privacypolicy/

我们采用行业标准的安全措施保护数据，但没有任何系统是绝对安全的，我们会尽最大努力防范数据泄露。

7. 数据留存与您的权利

评论数据将被留存以供展示，直至您主动要求删除。您有权随时通过 support@crclare.top 向我们申请导出或彻底删除您的评论记录及关联的 IP 信息。

8. 联系我们

如有任何关于隐私政策的疑问、安全漏洞报告或数据审计需求，请联系：support@crclare.top。
