## 🌌 我们在做什么

CrCLARE Studio 是一个由 **CLARE** 创立的独立开发者工作室。我们相信技术应当拥抱创造力，而非成为门槛。从底层的二进制安全，到跨越千年的文字叙事，我们永远站在独立创作者这一边。

我们敬畏开源的力量，也珍视每一份纯粹的热爱。工作室永远欢迎志同道合的朋友一起交流、协作，来去自由，只为创造出 Wonderful Code 和 Wonderful World。
